# Proyecto 4 JavaScript: Estructuras, Ciclos y Objetos

## 📝 Descripción del Proyecto
Este proyecto recopila los desafíos y ejercicios prácticos que desarrollé a lo largo del curso. Construí el código paso a paso, implementando de manera secuencial cada uno de los requerimientos solicitados para afianzar mis conocimientos en los fundamentos de JavaScript.

## 🚀 Cómo Ejecutar el Código
1. Abrir el archivo HTML asociado al script.
2. **Importante:** Al abrir o recargar la página, el navegador te solicitará dos valores mediante ventanas emergentes (`prompt`). Para visualizar correctamente las condiciones lógicas configuradas, **debes ingresar los datos 10 y 5** (10 para el primer número y 5 para el segundo).
3. Abrir la consola de desarrollador en tu navegador web (presionando **F12** o clic derecho -> *Inspeccionar* -> pestaña *Consola*), ahi se reflejara todos los datos implementados en el proyecto.

## 🛠️ Funcionalidades Implementadas
A lo largo del archivo organizé el código para cubrir los siguientes temas del curso:
* **Entrada y captura de datos:** Uso de `prompt` y conversión de tipos con `parseFloat`.
* **Estructuras de control:** Condicionales `if`, `if/else` y un bloque `switch` para evaluar los resultados de las operaciones matemáticas básicas.
* **Ciclos y Arreglos:** Recorrido de una lista de números comparando el comportamiento de un ciclo `for...in` frente a un ciclo `while` con contador manual.
* **Funciones:** Creación de funciones modulares con parámetros y retorno de valor para las operaciones, además de una función secundaria encargada de filtrar arreglos sin alterar los datos originales.
* **Estructuras de Objetos:** Definición de un objeto complejo que almacena un arreglo de ciudades, mostrando los registros reales mediante el método `.forEach()`.

## 🧠 Aprendizaje Obtenido
Gracias a este desarrollo paso a paso, logré comprender la diferencia fundamental entre el recorrido por propiedades que hace `for...in` y el control preciso que ofrece un bucle `while`. También aprendí el valor de la inmutabilidad al crear funciones de filtrado que aíslan la información sin corromper el flujo principal del programa, y cómo estructurar datos del mundo real utilizando arreglos de objetos.
